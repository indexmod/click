# CLICK — NTS Live

A small responsive static website with six interactive circles. Clicking any circle starts the supplied NTS live stream and changes that circle to ultramarine.

## Run locally

Open `index.html` in a modern browser. If the browser blocks the audio stream from a local file, serve the folder with any simple static server.

## Publish on GitHub

1. Create a new empty repository on GitHub.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md`.
3. In the repository settings, enable GitHub Pages from the default branch and root folder.

The stream URL is defined in `script.js` as `https://stream-mixtape-geo.ntslive.net/mixtape`.
